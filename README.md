# Video Compare
Side-by-side comparison of videos generated by different AI models

## Overview
VideoCompare is a web-based tool that allows you to compare videos generated by different AI models side by side. The application displays video pairs with their corresponding prompts, making it easy to evaluate and compare the quality and characteristics of different AI-generated videos.

## Prerequisites
- Python 3.x installed on your system
- A modern web browser (Chrome, Firefox, Safari, or Edge)

## How to Run

### Option 1: Using the Batch File (Windows)
1. Double-click on `start_server.bat`
2. A command prompt window will open and the server will start
3. Open your web browser and navigate to `http://localhost:8000`
4. The video comparison interface will load automatically

### Option 2: Using Python Directly
1. Open a terminal/command prompt in the project directory
2. Run the following command:
   ```
   python server.py
   ```
3. You should see output similar to:
   ```
   Starting server at http://localhost:8000
   Serving files from: C:\Code\VideoCompare
   Press Ctrl+C to stop the server
   ```
4. Open your web browser and navigate to `http://localhost:8000`

## Usage
1. Once the web interface loads, you'll see a list of video comparisons
2. Each comparison shows:
   - The original prompt used to generate the videos
   - Two videos side by side (Model1 vs Model2)
   - Video controls to play, pause, and scrub through the videos
3. Use the video controls to compare how each model interpreted the same prompt
4. Videos can be played independently or synchronized for direct comparison

## Project Structure
```
VideoCompare/
├── index.html          # Main web interface
├── videocompare.js     # JavaScript functionality
├── server.py          # Python HTTP server
├── start_server.bat   # Windows batch file to start server
├── videos.json        # Configuration file with video pairs and prompts
├── Model1/            # Videos generated by AI model 1
└── Model2/            # Videos generated by AI model 2
```

## Adding New Video Comparisons
To add new video pairs for comparison:
1. Place the videos in their respective `Model1/` and `Model2/` directories
2. Update the `videos.json` file with the new video paths and prompt
3. Follow this format:
   ```json
   {
     "model1_path": "Model1/your_video_name.mp4",
     "model2_path": "Model2/your_video_name.mp4",
     "prompt": "Your prompt text here"
   }
   ```

## Stopping the Server
- Press `Ctrl+C` in the terminal/command prompt where the server is running
- Close the command prompt window (if using the batch file)

## Troubleshooting
- **Port already in use**: If you see an error about port 8000 being in use, close other applications that might be using this port or modify the `PORT` variable in `server.py`
- **Videos not loading**: Ensure all video files referenced in `videos.json` exist in their specified directories
- **Browser compatibility**: Use a modern browser that supports HTML5 video playback
